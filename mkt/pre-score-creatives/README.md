# 出分前阶段广告创意素材

定位：分数出来之前，引导高三家长先做志愿方向准备，而不是直接填报最终方案。

## 九宫格整体句

出分之前 专业方向 院校城市 志愿风险 一次理清 出分之后 再看位次 定冲稳保 心里不慌
